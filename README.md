# 50M Agent Utility Gateway

Production x402-paid API gateway for 50,000,000 internal logical agent slots.

- Settlement: Base mainnet USDC
- Pay-to: 0xf744573cdfFC211163c11c0a31730851Da78f708
- Facilitator: OpenX402
- Seller API keys: none
- Discovery: /.well-known/x402
- OpenAPI: /openapi.json

Paid endpoints are deterministic utilities priced from $0.001 to $0.002 per request. The receiving wallet private key is never required by this server.
